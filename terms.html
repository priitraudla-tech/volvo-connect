Volvo Connect – Terms and Privacy

Last updated: 25 November 2026

1. What this application is

Volvo Connect is a private, non-commercial tool made by Priit Raudla for use with his own Volvo car. It is not offered to the public and has no other users.

2. What it does

With the car owner's consent given through Volvo ID, the application uses the Volvo Cars Connected Vehicle API to read vehicle status (odometer, fuel level, trip statistics, lock and engine status) and to send remote commands that the owner requests (lock, unlock, engine start and stop, honk and flash).

3. Data

Vehicle data and access tokens are stored only on the owner's own computer. The data is used only to show the owner the state of the car and a personal record of distance driven and running costs. No data is sold, shared with third parties or used for advertising.

4. Revoking access

The owner can revoke access at any time in the Volvo ID account settings or by deleting the application in the Volvo Cars Developer Portal. Locally stored data can be deleted by removing the application folder.

The application is provided as is, for personal use. Remote commands are only sent on the owner's explicit request and in line with local laws on remote engine start.
